# i-um Legal Site

This directory contains the public legal pages for the i-um mobile app.

Expected GitHub Pages URLs after the `Legal Pages` workflow is enabled and deployed:

```text
https://twotwobread.github.io/i-um/
https://twotwobread.github.io/i-um/terms/
https://twotwobread.github.io/i-um/privacy/
```

Only this `legal-site/` directory is uploaded to GitHub Pages. The repository `docs/` directory is intentionally not published because it contains internal feature and delivery documents.

Before external production launch, replace the MVP contact/provider placeholders in the legal text with final operator, business, and privacy contact details.
